Один экран, произвольное число списков, локальная база без интернета.

## Списки

- Любое количество своих списков поверх трёх встроенных
- Счётчик незакрытых дел на каждой вкладке
- Свои списки удаляются вместе с содержимым, встроенные защищены
- Поиск в текущем списке или сразу во всех
- Перетаскивание за ручку меняет ручной порядок, у краёв список сам доскроллится

## Дела

- Добавление и редактирование (в том числе у покупок — раньше это было недоступно)
- Важность: обычное / важное / срочное, показывается полосой слева
- Срок с календарём; просроченные подсвечиваются, «Сегодня» и «Завтра» подписываются словами
- Отметка выполнения вместо удаления: элемент уезжает вниз и зачёркивается
- Сортировка: вручную, по важности, по сроку, по алфавиту
- Перенос между списками, удаление с отменой через Snackbar

## Покупки

- Количество («2 кг») и цена у каждого товара
- Итоговая сумма по незакрытым позициям внизу списка
- Чекбокс «куплено» с зачёркиванием вместо мгновенного удаления

## Быстрый ввод

- Виджет на рабочий стол со списком и кнопкой «+»
- Приём текста из других приложений через «Поделиться»
- «Добавить в задачи» из контекстного меню выделенного текста

## Техническое

- Kotlin, одна `Activity`, `RecyclerView` + `DiffUtil` + `ItemTouchHelper`
- Room с реактивными `Flow`, `MainViewModel` отдаёт `StateFlow<MainUiState>`
- Настоящая миграция БД 1 → 2: категория стала таблицей, элемент получил
  выполнение, приоритет, срок, количество и цену
- Тёмная тема, все строки в `strings.xml`, векторные иконки
- 11 инструментальных тестов: миграция, каскады, позиции, сортировка, поиск, суммы

## Сборка

Требуется JDK 17+ (подойдёт JBR из Android Studio).

```bash
./gradlew assembleDebug        # сборка
./gradlew connectedDebugAndroidTest   # тесты на подключённом устройстве или эмуляторе
```

В `gradle.properties` оставлены два флага AGP 9 — `android.builtInKotlin=false`
и `android.newDsl=false`. Это штатный обход, который AGP предлагает в тексте
ошибки: плагин `kotlin-android` с AGP 9 несовместим, а KSP конфликтует со
встроенным Kotlin. Флаги помечены deprecated и исчезнут в AGP 10.
